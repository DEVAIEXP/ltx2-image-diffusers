# LTX 2.3 Image Modular Blocks

Experimental Modular Diffusers blocks for the LTX 2.3 image-only pipeline.

This first pass targets distilled text-to-image parity with `run_distilled.py`.
Image-to-image, PAG, and LoRA support should be added only after the distilled
text-to-image path matches the current standard pipeline output.

See [EXPERIMENTS.md](EXPERIMENTS.md) for benchmark notes, memory-manager findings, and the current experimental baseline.
